Ik wil graag mijn nieuwe Vectorworks plugin **Pretty Patchlist** laten zien.

Het stoorde mij al langer dat Vectorworks geen ingebouwde generator heeft voor een goed opgemaakte DMX-patchlijst. Veel gebruikers maken hun patchlijsten daarom in een ander programma.

Met worksheets kan het ook, maar het kost veel tijd om meerdere database rows netjes op te maken met randen, headers en subheaders. Ook het onderhouden van afzonderlijke patches per universe en fixture type wordt al snel omslachtig. Het ene project heeft vier universes en vijf fixture types, terwijl een volgend project er vijftig en veertien kan hebben.

Pretty Patchlist automatiseert dit proces. De plugin scant de Lighting Devices in je document, herkent de unieke universes en fixture types en maakt voor iedere combinatie een afzonderlijke database row in een overzichtelijk opgemaakte worksheet.

De plugin biedt onder meer:

- een titelheader met informatie uit je title block record
- overzichten per fixture type en universe
- een volledig aanpasbare kolomindeling
- ondersteuning voor user fields, zoals een eigen Fixture Mode-veld
- system filters die je met één handeling op alle database rows toepast
- opgeslagen instellingen om je vaste indeling en configuratie snel opnieuw te gebruiken

Pretty Patchlist begon ruim vijf jaar geleden als mijn eerste Vectorworks Python-project. Sindsdien gebruikte ik het zelf als los script. Nu is het beschikbaar als installeerbare plugin voor iedereen die er net zo veel gemak van heeft als ik.

[Bekijk Pretty Patchlist op STB-VW Tools](https://stb-vw.com/plugins/pretty-patch-list/)

Op dezelfde website vind je ook mijn andere Vectorworks plugin, [Symbol Line](https://stb-vw.com/plugins/symbol-line/).
